# Khorablo Assignment 02

RGB color detection exercise implemented in multiple languages.

## Files

| File | Description |
| --- | --- |
| `main.py` | Python implementation. |
| `main.c` | C implementation. |
| `main.pl` | Perl implementation. |
| `265c6d91-bc5c-45cf-a6e3-db52366683e5.pdf` | Assignment document. |

## Run

Python:

```bash
python3 main.py
```

C:

```bash
gcc main.c -lm -o color-detect
./color-detect
```

Perl:

```bash
perl main.pl
```
