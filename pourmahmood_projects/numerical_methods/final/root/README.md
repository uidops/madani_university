# Root Finding

Numerical root-finding project with method comparison, convergence analysis, reports, and plots.

## Files

| File | Description |
| --- | --- |
| `main.py` | Root-finding method implementations and analysis helpers. |
| `project1.py` | Full report-generation workflow using plotting and symbolic tools. |
| `Untitled-1.py` | Additional experimental script. |
| `output.md` | Generated markdown report. |
| `output.html` | Generated HTML report. |
| `output.pdf` | Generated PDF report. |
| `plots/` | Generated graphs for methods and stopping criteria. |

## Methods Covered

- Bisection
- Newton
- Secant
- Fixed-point iteration
- Aitken acceleration

## Run

Install dependencies as needed:

```bash
python3 -m pip install numpy matplotlib sympy markdown weasyprint
```

Run the main script:

```bash
python3 main.py
```

Run the report workflow:

```bash
python3 project1.py
```

## Notes

- Generated plots and reports are kept with the project for reference.
- Some PDF generation features depend on local WeasyPrint system requirements.
