# Equation Solver

System of linear equations solver using Cramer's rule.

## Files

| File | Description |
| --- | --- |
| `equation_solver.py` | Parser, determinant calculation, Cramer's rule solver, and report generation. |
| `example1_solution.md` | Example solution report. |
| `example2_solution.md` | Example solution report. |
| `production_optimization.md` | Applied optimization example or report. |

## Run

Install NumPy if needed:

```bash
python3 -m pip install numpy
```

Run the solver:

```bash
python3 equation_solver.py
```

## Notes

- The solver is focused on `3x3` systems with variables `x`, `y`, and `z`.
- Markdown reports are generated from the calculation steps.
