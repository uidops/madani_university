# Web Designing

Web-designing coursework for Professor Sodabeh Imanzadeh.

## Projects

| Directory | Description |
| --- | --- |
| `01/` | Static resume page built with HTML and CSS. |
| `02/` | RTL Persian shop demo built with HTML, CSS, JavaScript, and JSON product data. |

Each project directory includes its own `README.md` with file details and run instructions.

## Run A Static Project

Open the project `index.html` file in a browser.

For projects that load local JSON data, use a local static server from the project directory:

```bash
python3 -m http.server
```
