# Resume Page

Static resume web page for the web-designing coursework.

## Files

| File | Description |
| --- | --- |
| `index.html` | Resume page markup. |
| `styles.css` | Layout, typography, cards, and responsive styling. |

## Run

Open `index.html` in a browser.

You can also serve the directory locally:

```bash
python3 -m http.server
```

Then open:

```text
http://localhost:8000
```

## Notes

- This is a static HTML/CSS exercise.
- No build step or external package installation is required.
