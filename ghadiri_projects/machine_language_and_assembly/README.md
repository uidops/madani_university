# Machine Language And Assembly

Course projects for Professor AliReza Ghadiri's machine language and assembly coursework. The projects focus on basic low-level programming, DOS interrupt-based input/output, and comparing simple C implementations with Assembly versions.

## Projects

| Project | Description |
| --- | --- |
| `factorial/` | Factorial calculation written in Assembly. |
| `pyramid/` | Star pyramid exercise implemented in C and Assembly. |


## Notes

- Assembly files target a DOS-style 8086 environment (EMU8086).
- C files can be compiled with a standard C compiler such as `gcc`.
- Generated binaries, emulator output files, and temporary build files should stay out of version control.
