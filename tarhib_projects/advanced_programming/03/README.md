# Assignment 03

NumPy practice script covering array data types, indexing, sorting, padding, matrix operations, and random arrays.

## Files

| File | Description |
| --- | --- |
| `main.py` | Demonstrates many NumPy array operations and prints their results. |

## Requirements

- Python 3
- NumPy

Install NumPy if needed:

```bash
python3 -m pip install numpy
```

## Run

```bash
python3 main.py
```

## Notes

- This is a learning/demo script and prints many examples in sequence.
