# N-Queen

Backtracking solution for the N-Queen problem implemented in Go.

## Files

| File | Description |
| --- | --- |
| `n-queen.go` | Safety checks, recursive solver, and board printing. |
| `go.mod` | Go module definition. |

## Run

From this directory:

```bash
go run .
```

## Notes

- The board size is set in `main`.
- Generated binaries such as `n-queen` should not be committed.
