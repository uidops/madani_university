# Spanning Tree

Prim-style minimum-spanning-tree exercise in Go and Python.

## Files

| File | Description |
| --- | --- |
| `prime.go` | Go implementation for building a minimum spanning tree from an adjacency matrix. |
| `derakht-poosha.py` | Python implementation of the same exercise. |
| `go.mod` | Go module definition. |

## Run The Go Version

From this directory:

```bash
go run .
```

## Run The Python Version

```bash
python3 derakht-poosha.py
```

## Notes

- The sample graph is defined in both source files.
- The programs print the spanning-tree matrix and total weight.
