# Activity Selection

Greedy activity-selection algorithm implemented in Go.

## Files

| File | Description |
| --- | --- |
| `activity_selection.go` | Activity model, greedy selection function, and sample input. |
| `go.mod` | Go module definition. |

## Run

From this directory:

```bash
go run .
```

## Notes

- Activities are sorted by finish time.
- The selected compatible activities are printed from the sample data in `main`.
