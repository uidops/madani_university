# Dijkstra

Dijkstra shortest-path exercise implemented in Go.

## Files

| File | Description |
| --- | --- |
| `dijkstra.go` | Graph conversion, Dijkstra implementation, and sample adjacency matrix. |
| `go.mod` | Go module definition. |

## Run

From this directory:

```bash
go run .
```

## Notes
- The program prints the selected shortest-path edge set for the sample graph.
