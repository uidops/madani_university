# Optimal Binary Search Tree

Optimal binary search tree dynamic-programming exercise.

## Files

| File | Description |
| --- | --- |
| `obst.go` | Go implementation that prints cost and root matrices. |
| `bst-behineh.py` | Python implementation of the same dynamic-programming idea. |
| `go.mod` | Go module definition. |

## Run The Go Version

From this directory:

```bash
go run .
```

## Run The Python Version

Install NumPy if needed:

```bash
python3 -m pip install numpy
```

Then run:

```bash
python3 bst-behineh.py
```

## Notes

- The sample probabilities are defined in each source file.
- Both versions print dynamic-programming matrices and the minimum expected cost.
