# Scheduling With Deadlines

Greedy job sequencing exercise implemented in Go.

## Files

| File | Description |
| --- | --- |
| `sched_deadline.go` | Job model, feasibility check, greedy scheduler, and sample input. |
| `go.mod` | Go module definition. |

## Run

From this directory:

```bash
go run .
```

## Notes

- Jobs are sorted by efficiency before selection.
- Generated binaries such as `sched_deadline` should not be committed.
