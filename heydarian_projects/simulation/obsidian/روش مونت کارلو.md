

## تمرین ۱۳: روش مونت کارلو
#### سطح زیر منحنی $y = x^2-3x+11$ را به دو روش ذوزنقه‌ای و روش مونت کارلو در بازه $[-4,5]$ محاسبه کنید.


#### روش انتگرال معین: 

$$f(x) = x^2 - 3x + 11$$$$\int_{-4}^{5} f(x)dx = \dfrac{x^3}{3} - \dfrac{3}{2}x^2 + 11x |_{-4}^{5} = (\dfrac{5^3}{3} - \dfrac{3(5)^2}{2} + 11(5)) - (\dfrac{(-4)^3}{3} - \dfrac{3(-4)^2}{2} + 11(-4)) =$$
$$(\dfrac{125}{3} - \dfrac{75}{2} + 55) - (\dfrac{-64}{3} - \dfrac{48}{2} - 44) = \dfrac{250 - 225 + 330}{6} - \dfrac{-128 -144 - 264}{6} = \dfrac{355}{6} + \dfrac{536}{6} = \dfrac{891 }{6} = 148.5$$


#### روش ذوزنقه‌ای:
$$\Delta x = \dfrac{b - a}{n} = \dfrac{5 + 4}{n} = 1 \rightarrow n = 9$$


$$y_0 = f(a) = f(-4) = 39$$
$$y_1 = f(a + \Delta x) = f(-3) = 29$$
$$y_2 = f(a + 2\Delta x) = f(-2) = 21$$
$$y_3 = f(a + 3\Delta x) = f(-1) = 15$$$$y_4 = f(a + 4\Delta x) = f(0) = 11$$$$y_5 = f(a + 5\Delta x) = f(1) = 9$$
$$y_6 = f(a + 6\Delta x) = f(2) = 9$$
$$y_7 = f(a + 7\Delta x) = f(3) = 11$$
$$y_8 = f(a + 8\Delta x) = f(4) = 15$$
$$y_9 = f(a + 9\Delta x) = f(5) = 21$$


$I \approx \Delta x\times (\dfrac{1}{2}y_0 + y_1 + y_2 + y_3 + y_4 + y_5 + y_6 + y_7 + y_8 + \dfrac{1}{2}y_9) = 1 \times(\dfrac{39}{2} + 29 + 21 + 15 + 11 + 9 + 9 + 11 + 15 + \dfrac{21}{2}) = 150$

### مونت کارلو:
