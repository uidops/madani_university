# Assignment 04

C exercises for linked-list operations.

## Files

| File | Description |
| --- | --- |
| `a.c` | Singly linked-list insertion and reverse-order printing exercise. |
| `b.c` | Circular linked-list exercise with node removal/traversal behavior. |

## Run

Compile and run each file separately.

```bash
gcc a.c -o a
./a
```

```bash
gcc b.c -o b
./b
```

## Notes

- These programs are small standalone C exercises.
- Generated binaries such as `a` and `b` should not be committed.
