# Assignment 05

C exercises for stack data structures, plus notes for expression conversion.

## Files

| File | Description |
| --- | --- |
| `1.c` | Linked-list stack with `push` and `pop` operations. |
| `2.c` | Two-stack implementation using one fixed-size array. |
| `3.txt` | Written notes for infix, prefix, and postfix expression conversion. |

## Run

Compile and run each C file separately.

```bash
gcc 1.c -o stack-list
./stack-list
```

```bash
gcc 2.c -o dual-stack
./dual-stack
```

## Notes

- `3.txt` is a written solution and does not need to be compiled.
- Generated binaries such as `stack-list` and `dual-stack` should not be committed.
